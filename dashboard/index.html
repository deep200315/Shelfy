How changes ship

feature/*→ develop→ release/v*→ main

Every arrow is a pull request gated by CI. Merging into develop deploys the Dev build; merging into main publishes the production release.

Shelfy is free and open source (MIT). Builds are ad-hoc signed: on first launch, right-click Shelfy.app → Open.
