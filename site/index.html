everything you need.
nothing you don't.

Built natively in Swift with AppKit and SwiftUI. It feels like part of macOS because it is.

01 · summon

Shake to open

Wiggle the pointer mid-drag, press ⌃⌥D, or drop onto the menu bar icon or the MacBook notch.

02 · move

Drop it all at once

Drag the pile to move everything, or open the list to reorder, rename, and drag single files out.

03 · act

Instant Actions

Drop straight onto AirDrop, Messages, Mail, or Compress without collecting first.

04 · smart

Suggested actions

Stitch images, make a PDF, merge PDFs, turn a video into a GIF, or shrink it, based on what's on the shelf.

05 · search

Command Bar

Press ⌘K and type. Every action, including your Shortcuts and custom scripts, is a few letters away.

06 · remember

Clipboard history

Your last 60 copies on a shelf. Anything a password manager marks as private is never recorded.

Download the app, or build it yourself: it's a plain Swift package with no dependencies. Every release is built, tested, and packaged in the open by GitHub Actions.

install or update with one command
$ curl -fsSL https://deep200315.github.io/Shelfy/install.sh | sh
or download
Download Shelfy.dmg
first launch after a .dmg download
  1. Open Shelfy.dmg and drag Shelfy into Applications.
  2. Open Shelfy. macOS blocks it the first time, because free builds aren't notarized by Apple.
  3. Go to System Settings → Privacy & Security, scroll down, and click Open Anyway.
  4. Look for the tray icon in your menu bar. Shelfy has no Dock icon or window.
build from source
$ git clone https://github.com/deep200315/Shelfy.git
$ cd Shelfy && ./build.sh && open build/Shelfy.app
latest work in progress
$ gh release download dev --repo deep200315/Shelfy --pattern '*.dmg'
